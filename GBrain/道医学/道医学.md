# 道医学

## 核心概念

道医学是道家思想与中医学的深度融合体系，以"道法自然"为哲学根基，将道家的精气神修炼理论与中医的阴阳五行、藏象经络体系贯通一体。

## 知识框架

| 维度 | 核心内容 |
|------|----------|
| **哲学基础** | 道法自然、无为而治、天人合一 |
| **理论体系** | 精气神学说、丹道理论、五行归真 |
| **诊断方法** | 道家望气、脉象精微、内观自诊 |
| **治疗手段** | 导引吐纳、祝由符箓、丹药炼制、针灸推拿 |
| **修炼体系** | 内丹术、外丹术、房中术、辟谷术 |
| **养生智慧** | 四时调摄、导引按跷、存思守一 |

## 与中医学的关系

道医学是中医学的重要源头和补充。中医经典《黄帝内经》本身就深受道家思想影响，道医则在中医基础上更强调：
- **治未病**：以修炼和养生为先，而非仅治已病
- **整体观**：将人体视为小宇宙，与天地大宇宙相应
- **神气并重**：不仅调理形质，更重精气神的整体调摄
