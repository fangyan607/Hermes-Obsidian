# 项目管理总索引

> 本索引页是整个多项目管理系统的入口。每个项目独立存放在 Projects/ 下的子目录中，遵循统一模板。

---

## 📋 项目管理系统说明

### 目录结构

```
Projects/
├── INDEX.md               ← 本文件，项目总索引
├── _模板/
│   ├── 项目总览.md        ← 项目模板，新建项目时复制
│   └── 周报模板.md        ← 每周报告模板
├── 项目A（示例）/         ← 示例项目（可删除）
│   └── 项目总览.md
├── <项目名称>/            ← 实际项目目录
│   ├── 项目总览.md        ← 项目总览（基于模板）
│   ├── 周报/              ← 每周周报
│   │   ├── 2025-W01.md
│   │   ├── 2025-W02.md
│   │   └── ...
│   ├── 笔记/              ← 项目相关笔记
│   └── 资源/              ← 附件、截图、设计稿等
└── ...
```

### 项目状态说明

| 状态 | 含义 |
|------|------|
| 🟢 **active** | 进行中，正在投入资源 |
| ✅ **completed** | 已完成，不再开发 |
| 🟡 **paused** | 暂时搁置，未来可能重启 |
| 🔴 **cancelled** | 已取消，不再推进 |

### 优先级说明

| 优先级 | 含义 |
|--------|------|
| 🔥 **high** | 高优先级，当前核心关注 |
| 📌 **medium** | 正常推进 |
| 💤 **low** | 低优先级，闲暇时处理 |

### 使用方式

1. **新建项目**：复制 `_模板/项目总览.md` 到新目录（如 `Projects/新项目/项目总览.md`）
2. **填写信息**：修改 frontmatter 中的状态、优先级、起止日期
3. **更新进展**：每周复制 `_模板/周报模板.md` 到项目 `周报/` 目录下
4. **维护索引**：在本页下方 `## 📌 活跃项目` / `## ✅ 已完成项目` 中添加链接
