## 1. 三大故事结构体系速览

### 1.1 救猫咪15节拍表

**来源**：布莱克·斯奈德《救猫咪》  
**适用**：商业类型片剧本结构规划  
**核心理念**：好剧本始于"电影讲什么"，通过高度概念化的故事线和15节拍将编剧转变为可操作的系统工程。

| 节拍 | 页码(110页) | 功能 | 关键问题 |
|------|------------|------|---------|
| **1. 开场画面** | 1 | 定基调、类型铺垫 | 主角的状态是什么？ |
| **2. 主题呈现** | 5 | 某人（通常非主角）点出故事主题 | 电影到底在说什么？ |
| **3. 铺垫** | 1-10 | 介绍A故事所有角色、主角的生活世界 | 主角的日常是怎样的？ |
| **4. 推动（催化剂）** | 12 | 震撼主人公的事件发生 | 什么打破了日常平衡？ |
| **5. 争论** | 12-25 | 主人公犹豫不决 | 主角为什么不敢行动？ |
| **6. 第二幕衔接点** | 25 | 进入第二幕，旅程正式开始 | 什么迫使主角做出选择？ |
| **7. B故事** | 30 | 爱情故事/主题讨论/副线开始 | 谁是B故事的主角（通常是与主题相关的角色）？ |
| **8. 游戏** | 30-55 | "影片许下的诺言"——展现影片核心乐趣 | 观众花钱要看的是什么？ |
| **9. 中点** | 55 | 假胜利或假失败，气氛紧张，倒计时开始 | 成败关键转折？ |
| **10. 坏人逼近** | 55-75 | 内外压力同时增大 | 对手如何收紧包围圈？ |
| **11. 一无所有** | 75 | 人为失败，"死亡气息" | 主角失去一切的时刻？ |
| **12. 灵魂黑夜** | 75-85 | 失去所有希望，深度反思 | 主角怎么重新站起来？ |
| **13. 第三幕衔接点** | 85 | B故事带来新灵感/解决方案 | 什么给了主角最后的力量？ |
| **14. 结局** | 85-110 | 两个世界的综合，最终对决 | 主角如何运用所学取胜？ |
| **15. 终场画面** | 110 | 与开场呼应，变化已发生 | 主角变得怎样了？ |

**关键技巧**：
- **"救猫咪"场面**：让主角做一件好事，使观众立刻喜欢他
- **开场与终场呼应**：对比展示主角的变化
- **静止=死亡**：给主角变化的理由，没有变化就没有故事

### 1.2 坎贝尔/沃格勒英雄旅程

**来源**：约瑟夫·坎贝尔《千面英雄》、克里斯托弗·沃格勒《作家之旅》  
**适用**：神话结构、史诗叙事、角色成长弧设计  
**核心理念**：单一神话（Monomyth）——所有伟大的故事都是同一个神话的不同版本。

#### Phase 1: 启程（Departure）

| 阶段 | 内容 | 剧作功能 |
|------|------|---------|
| **1. 平凡世界** | 英雄在日常世界 | 建立主角正常生活（对应救猫咪1-3） |
| **2. 冒险召唤** | 英雄受到冒险的呼唤 | 推动事件（对应救猫咪4） |
| **3. 拒绝召唤** | 英雄犹豫不决 | 争论（对应救猫咪5） |
| **4. 遇见导师** | 遇到智慧引导者 | 获得帮助与指导 |
| **5. 跨越第一道门槛** | 进入非常世界 | 第二幕衔接点（对应救猫咪6） |
| **6. 鲸鱼之腹** | 进入未知领域 | 面临最初的挑战 |

#### Phase 2: 启蒙（Initiation）

| 阶段 | 内容 | 剧作功能 |
|------|------|---------|
| **7. 考验之路** | 一系列挑战 | 游戏时刻（对应救猫咪8） |
| **8. 遇到女神** | 遇到爱/灵感对象 | B故事/爱情线 |
| **9. 妖妇的诱惑** | 被诱惑偏离正途 | 角色内心的黑暗面 |
| **10. 与父亲和解** | 面对权威/内心阴影 | 中点前后的自我认知 |
| **11. 神化（Apotheosis）** | 领悟更高真理 | 灵魂黑夜后的顿悟 |
| **12. 终极恩赐** | 赢得决定性胜利 | 中点/第三幕的转折 |

#### Phase 3: 归来（Return）

| 阶段 | 内容 | 剧作功能 |
|------|------|---------|
| **13. 拒绝归来** | 不想回到平凡世界 | 角色已改变 |
| **14. 借助魔法逃脱** | 在外力帮助下返回 | 第三幕衔接 |
| **15. 从外部救援** | 被伙伴/导师救出 | 团队协作 |
| **16. 跨越归来的门槛** | 回到平凡世界 | 第三幕开始 |
| **17. 两个世界的主人** | 掌握两个世界的力量 | 结局中的主角升华 |
| **18. 自由地生活** | 带着智慧/礼物回归 | 终场画面 |

**坎贝尔名言**："决心成为自己，是一种英雄气概。遵循内在的喜悦，追求生命的经验。"

### 1.3 埃里克·埃德森23英雄目标段落

**来源**：埃里克·埃德森《故事策略——电影剧本必备的23个故事段落》  
**适用**：第二幕情节构建、商业类型片节拍精确定位  
**核心理念**：每一部票房成功的电影都包含同样的23个渐进的故事行动——英雄目标序列（Hero Goal Sequences）。

#### 第一幕：6个段落（建立+惊人意外#1）

| 段落 | 名称 | 核心功能 |
|------|------|---------|
| **#1** | 建立日常世界 | 展示主角生活、让观众喜欢主角、揭示保护壳、不公平伤害、对现状不满 |
| **#2** | 总体冲突展开 | 引发事件常在此出现、揭示主角内心情感伤痛 |
| **#3** | 历险召唤 | 新人物登场、故事节奏加快、爱恋对象/情感挑战出现、陷阱布好 |
| **#4** | 关系发展 | 导师/爱恋对象/伙伴登场、主角被迫冒险、掉入陷阱 |
| **#5** | 渴望揭示 | 主角主要渴望揭示、对手力量首次呈现、拒绝召唤 |
| **#6** | 惊人意外#1 | 陷阱机关触发、第一幕结束、第二幕主线目标明确 |

#### 第二幕前半段：6个段落（#7-#12）

| 段落 | 名称 | 核心功能 |
|------|------|---------|
| **#7** | 寻觅良策 | 主角制定计划、承担特定目标、内心冲突浮现、辨明敌友 |
| **#8** | 展现力量/训练 | 对手力量显露、风险递增、主角受训、人物成长第一步（表达时刻） |
| **#9** | 行动迸发 | 行动迸发/强烈情绪、主角展现能力、冒险失败、考虑放弃 |
| **#10** | 受挫/新导师 | 主角受挫、请教新导师、意外阻碍出现、次要情节展开 |
| **#11** | 接近虎穴 | 接近对手权力中心、冲突激烈、与代理人战斗、最后受训机会 |
| **#12** | 中间点 | 无路可退、恋人结合/搭档合作、卸下假面、倒计时开始、象征性死亡与重生 |

#### 第二幕后半段：6个段落（#13-#18）

| 段落 | 名称 | 核心功能 |
|------|------|---------|
| **#13** | 重拾决心 | 新难题出现、主角退回保护壳、冲突变得更个人化 |
| **#14** | 沉思时刻 | 节奏放缓、提出内心冲突问题、重要新想法出现 |
| **#15** | 第二次行动迸发 | 行动迸发、**胜利假象（False Victory）**、短暂安全感 |
| **#16** | 能量持续抬升 | 冲突强度递增、主角新视角、人物成长第三步（战胜内心冲突） |
| **#17** | 决战准备 | 最后准备、对手力量以个人方式展现、倒计时接近零点 |
| **#18** | **惊人意外#2** | 第二幕高潮、故事最大反转（通常是消极的）、恋情中的谎言被揭露 |

#### 第三幕：2-5个段落（#19-#23）

| 段落 | 名称 | 核心功能 |
|------|------|---------|
| **#19** | 重整旗鼓 | （消极反转时）理清思路，或结束次要情节 |
| **#20** | **必需场景** | 主角与对手最后对决，核心冲突彻底解决 |
| **#21** | 次要情节收尾 | 视需要而定 |
| **#22-##** | **结局** | 回到正常世界，所有故事线收束，与开场呼应 |

**第三幕要点**：
1. 主角必须自己引发结局——不能由别人代劳
2. 惊人意外#2摧毁了主角的计划，他必须在第三幕即兴应战
3. 必需场景不可或缺
4. 所有关键次要情节必须有始有终
5. 结局必须紧随必需场景

## 2. 角色创作

### 2.1 角色原型速查

基于《故事策略》的七种核心原型 + 其他补充原型：

| 原型 | 功能 | 关键特征 | 片例 |
|------|------|---------|------|
| **主人公** | 故事推动者，带着紧迫目标 | 需有情感保护壳、有成长空间 | 杰克（《泰坦尼克号》） |
| **对手/反派** | 最强对抗力量 | 自视为自己故事的主人公、通常有帮手 | 特工史密斯（《黑客帝国》） |
| **爱恋对象** | 挑战主角情感世界 | 常作为情感对手出现，主角成长的回报 | 玛丽·简（《蜘蛛侠》） |
| **导师** | 传授技能/信息 | 常会死去、赠予保命礼物 | 墨菲斯（《黑客帝国》） |
| **伙伴** | 与主角并肩作战 | 挑战主角动机、带来喜剧调剂、不能死 | 多利（《海底总动员》） |
| **帮手/追随者** | 提供特殊才能 | 主角自身没有的技能 | 道格（《飞屋环游记》） |
| **反派的代理人** | 效命于反派 | 为主角设置直接障碍 | 阿尔法狗（《飞屋环游记》） |
| **独立的麻烦制造者** | 与反派无关的障碍 | 提供另一个需要证明的竞技场 | 建筑工头（《飞屋环游记》） |
| **边界护卫** | 拒绝主角进入 | 考验主角的决心，后可转为盟友 | 马丁·汉森（《美丽心灵》） |

**角色关系口诀**：主角有目标，反派挡他去，导师给帮助，伙伴来陪伴，爱恋促成长。

### 2.2 人物成长弧

**核心概念**：主人公从**幼稚到成熟**的情感之旅，从**身份到本质**的转变——从戴着自我保护面具、躲避真实情感，到卸下假面、坦诚生活。

#### 人物成长三步走

| 步骤 | 出现段落 | 内容 | 片例 |
|------|---------|------|------|
| **第一步：表达需求** | #7-#10（常#8） | 主角/亲近之人表达内心冲突的本质 | 《尽善尽美》"如果生活就是这样呢？" |
| **第二步：对抗冲突** | #12（中间点） | 主角直接对抗阻碍成长的内心冲突 | 《永不妥协》艾琳叫板首席律师 |
| **第三步：战胜冲突** | #16-#17 | 主角以行动战胜内心冲突，证明改变 | 《海底总动员》马林学会放手 |

#### 人物保护壳 vs 真实创伤

| 层次 | 出现时间 | 说明 | 片例 |
|------|---------|------|------|
| **保护壳** | #1 | 主角如何保护自己不被伤害 | 《怪物史莱克》——绿怪说"像洋葱一样层层包裹" |
| **情感伤痛** | #2 | 痛苦的表征，但未揭示原因 | 《雨人》查理谈到与父亲不和的受伤感 |
| **真正创伤** | 中间点前后 | 引起情感伤痛的过往事件被揭示 | 《雨人》查理记起"雨人"哥哥被带走 |

---

### 2.3 主角共鸣工具

**让观众立刻喜欢主角的六大工具**（用于23段落#1）：

1. **能力展示**：主角在擅长领域表现得出色（出租车司机麦克斯的清洁与专业）
2. **同情心**：主角遭受不公平的伤害（求职场面试失败+违章罚单+被撞）
3. **勇敢/正义**：主角挺身而出保护弱者（巴德教训家暴假释犯）
4. **幽默感**：主角的机智应对
5. **秘密伤痛**：暗示主角不为人知的内心创伤
6. **"救猫咪"**：主角做一件不求回报的好事

## 3. 对白设计

> 来源：罗伯特·麦基《对白：文字·舞台·银幕的言语行为艺术》

### 3.1 对白三功能

| 功能 | 说明 | 原则 |
|------|------|------|
| **暴露信息** | 传递情节所需的事实 | 避免"信息倾倒"——通过冲突和行动自然揭示 |
| **塑造角色** | 通过说话方式揭示角色性格 | 表达三要素：内容、形式、技巧 |
| **推动情节** | 对白即行动，改变局面 | 每一句对白都应推动场景的发展方向 |

### 3.2 潜台词与文本

**文本**（Text）：角色实际说出来的话
**潜台词**（Subtext）：角色真正想表达的意思

**经典公式**：
> 好的对白 = 文本 × 潜台词

**技巧**：
- 角色说的 ≠ 角色想的
- 在不回避真相的前提下，让角色说的和想的不同
- 使用**戏剧性反讽**：观众知道但角色不知道的信息
- 使用**反讽**：自相矛盾、命运的剧变

### 3.3 对白瑕疵修正

| 瑕疵类型 | 表现 | 修正方法 |
|---------|------|---------|
| **可信性瑕疵** | 不像这个角色会说的话 | 重写以匹配角色专属词汇库、语法、节奏 |
| **语言瑕疵** | 太文雅/太粗俗/太啰嗦 | 根据角色身份调整语言层次 |
| **内容瑕疵** | 信息倾倒/说教 | 将信息融入冲突中自然流露 |
| **设计瑕疵** | 节奏不对/过于冗长 | 精简——让每一句话都有不可替代的功能 |

**六项对白任务检查**：每一句对白是否完成了它在该场景中的独特功能？

### 3.4 冲突类型

麦基提出的六种对白场景冲突设计：

| 冲突类型 | 说明 | 适用 |
|---------|------|------|
| **均衡冲突** | 双方势均力敌 | 正反对决 |
| **喜剧冲突** | 权力不对等导致的幽默 | 喜剧场景 |
| **不对称冲突** | 一方处于绝对劣势 | 追逐、审讯 |
| **非直接冲突** | 通过第三方传递 | 社会阶层差异 |
| **自反性冲突** | 角色与自己斗争 | 内心挣扎 |
| **微限冲突** | 极小差异引发的激烈冲突 | 亲密关系破裂 |

## 4. 场景构建与分析

> 来源：理查德·D·佩帕曼《拆解好电影：经典场景赏析》

### 4.1 场景四分类

根据场景的总体「感觉」将其归入四类：

| 类型 | 核心情绪 | 适用类型 | 片例 |
|------|---------|---------|------|
| **危险** | 冒险、威胁、险境、凶兆 | 悬疑、恐怖、惊险片 | 《虎豹小霸王》火车抢劫 |
| **高兴** | 着迷、享乐、幸福、满足 | 喜剧、着迷场景 | — |
| **壮举** | 英勇事迹、大胆的尝试 | 冒险片 | — |
| **吸引** | 引诱、勾引、诱惑 | 浪漫、欲望场景 | — |

> 注意：类别之间有交叉，选择最主导的情绪。

### 4.2 场景六大分析要素

| 要素 | 分析内容 | 关键问题 |
|------|---------|---------|
| **1. 故事梗概** | 一句话概括 | 这个场景对整体叙事的贡献是什么？ |
| **2. 角色活动** | 身体动作 + 物件使用 + 对白 | 每个角色在场景中的三项主要活动？ |
| **3. 场景涵义** | 文本 vs 潜台词 | 表面和实际在说什么？ |
| **4. 叙事工具** | 戏剧性反讽/反讽 | 观众比角色知道得多吗？ |
| **5. 镜头设置** | 从远景到特写排列 | 摄影机运动和景别选择如何服务叙事？ |
| **6. 重要选择** | 声音、对比、节奏、摄影机动机 | 导演的关键创作决策是什么？ |

### 4.3 伟大场景的关键原则

1. **场景必须有结构**：每个场景都有起承转合，自身就是一个微型故事
2. **场景推动故事或角色**：如果删掉这个场景不影响理解和情感，它就不该存在
3. **冲突是场景的灵魂**：没有冲突就没有戏剧
4. **潜台词比台词重要**：观众感受的远比角色说出的更强大
5. **镜头服务于情感**：选择什么景别、如何运动，都取决于你想让观众感受到什么

## 5. 救猫咪十大题材

> 来源：布莱克·斯奈德《救猫咪》

| # | 题材 | 核心公式 | 经典片例 |
|---|------|---------|---------|
| **1. 鬼怪屋** | 怪兽 + 封闭空间 + 原罪 | 一个或几个人被困在有限空间内，被怪物猎杀 | 《大白鲨》《异形》 |
| **2. 金羊毛** | 旅程 + 寻宝 + 自我发现 | 主角踏上旅程寻找某物，途中发现真正的宝藏是自己 | 《星球大战》《绿野仙踪》 |
| **3. 如愿以偿** | 魔法/奇迹 + 变化 + 教训 | 主角获得超自然能力或愿望成真，但最终发现教训 | 《大话王》《冒牌天神》 |
| **4. 麻烦家伙** | 普通人 + 突发危机 + 生存 | 一个普通人被卷入危机事件，必须靠本能求生存 | 《虎胆龙威》《泰坦尼克号》 |
| **5. 变迁仪式** | 生活变迁 + 成长烦恼 | 主角经历人生过渡期的痛苦与成长 | 《克莱默夫妇》《普通人》 |
| **6. 伙伴之情** | 搭档关系 + 爱情/友情 | 两个本不该在一起的人因为某种原因成为搭档 | 《雨人》《当哈利遇上莎莉》 |
| **7. 推理侦探** | 侦探 + 罪恶 + 真相 | 有人揭开一个秘密或调查一桩罪恶 | 《唐人街》《冰血暴》 |
| **8. 愚者成功** | 凡人 + 跳龙门 | 一个不起眼的小人物逆袭成功 | 《阿甘正传》《律政俏佳人》 |
| **9. 被制度化** | 个人 vs 集体 | 个人反抗体制，或发现无法逃脱体制 | 《飞越疯人院》《教父》 |
| **10. 超级英雄** | 特殊生物 + 小人国 | 一个与众不同的人在平凡世界中寻找自己的位置 | 《超人》《角斗士》 |

**题材选择检查**：
- [ ] 故事能归入某一种题材吗？
- [ ] 同类题材的经典影片有哪些规则？
- [ ] 我的故事做到了"似而不同"吗？
