## 一、按领域检索

### 1.1 列出某领域所有实体

```dataview
TABLE type AS "类型", relations AS "关系连接"
FROM "GBrain"
WHERE domain = "心理学"
SORT type ASC
```

**替换 `心理学` 为任意领域**：法律、创造性思维、学习方法、中医学、新科技与应用、写作

### 1.2 按领域统计实体分布

```dataview
TABLE rows.file.name AS "实体", rows.type AS "类型"
FROM "GBrain"
GROUP BY domain
SORT domain ASC
```

### 1.3 获取领域的关系图谱简述

```dataview
TABLE domain AS "领域", type AS "实体类型", relations AS "主要关系"
FROM "GBrain"
WHERE domain = "中医学" AND type = "theory"
SORT file.name ASC
```

## 二、按实体类型检索

### 2.1 查找所有理论型实体

```dataview
TABLE domain AS "领域", file.name AS "实体名"
FROM "GBrain"
WHERE type = "theory"
SORT domain ASC
```

### 2.2 按类型分组汇总

```dataview
TABLE rows.file.name AS "实体列表"
FROM "GBrain"
FLATTEN type
GROUP BY type AS "实体类型"
SORT type ASC
```

### 2.3 可用实体类型对照

| 类型 | 说明 | 典型实体 |
|------|------|----------|
| `concept` | 核心概念 | 世界模型、故事理论、创造力 |
| `theory` | 理论体系 | 阴阳五行、精神分析、认知科学 |
| `method` | 方法论 | 刻意练习、创意写作、设计思维 |
| `practice` | 实践体系 | 辨证论治、方剂配伍 |
| `technology` | 技术 | 量子计算、脑机接口 |
| `law` | 法律 | 民法典、合同法、刑法 |
| `therapy` | 疗法 | 认知行为疗法 |
| `technique` | 技法 | 修辞与描写 |

## 三、跨域连接检索

### 3.1 查找所有跨域连接

```dataview
TABLE file.name AS "实体", relations AS "关系", domain AS "领域"
FROM "GBrain"
WHERE contains(relations, "跨域关联")
SORT domain ASC
```

### 3.2 查找连接了多个领域的枢纽实体

```dataview
TABLE length(relations) AS "连接数", domain AS "领域"
FROM "GBrain"
WHERE length(relations) >= 3
SORT length(relations) DESC
```

### 3.3 某实体连接到哪些领域

以"系统思考"为例：

```dataview
TABLE relations, domain
FROM "GBrain"
WHERE file.name = "系统思考"
```

## 四、关系路径查询

### 4.1 按关系类型过滤

查找所有 `理论基础` 关系：

```dataview
TABLE file.name AS "实体", relations AS "关系"
FROM "GBrain"
WHERE contains(relations, "理论基础")
```

### 4.2 查找为其他实体提供"基础"的根实体

```dataview
TABLE file.name AS "实体", domain AS "领域"
FROM "GBrain"
WHERE contains(relations, "理论基础") OR contains(relations, "基础")
SORT domain ASC
```

### 4.3 查找特定关系类型的配对

```dataview
TABLE file.name AS "源实体", relations AS "目标关系"
FROM "GBrain"
WHERE any(relations, (r) => contains(r.type, "跨域"))
SORT file.name ASC
```

## 五、关键词全文搜索

### 5.1 搜索实体定义中的关键词

> 在 Obsidian 中按 `Ctrl+Shift+F` 或使用搜索面板：

```
path:GBrain "心流"
```

### 5.2 搜索标题中的关键词

```
path:GBrain 深度
```

### 5.3 组合搜索（标题 + 内容）

```
path:GBrain ("神经网络" OR "深度学习")
```

### 5.4 排除特定领域

```
path:GBrain 练习 -path:法律
```

### 5.5 Obsidian 搜索运算符速查

| 运算符 | 用法 | 说明 |
|--------|------|------|
| `path:` | `path:GBrain` | 限定搜索路径 |
| `"` | `"刻意练习"` | 精确短语匹配 |
| `OR` | `A OR B` | 或条件 |
| `-` | `-path:法律` | 排除 |
| `file:` | `file:"深度工作"` | 按文件名搜索 |
| `tag:` | `tag:#gbrain` | 按标签搜索 |
| `line:` | `line:(核心要点)` | 行内搜索 |

## 六、按标签检索

### 6.1 查找包含特定标签的实体

```dataview
TABLE domain AS "领域", tags AS "标签"
FROM "GBrain"
WHERE contains(tags, "专注")
SORT domain ASC
```

### 6.2 列出所有标签及其出现次数

```dataview
TABLE rows.file.name AS "实体", rows.domain AS "领域"
FROM "GBrain"
FLATTEN tags
GROUP BY tags AS "标签"
SORT length(rows) DESC
```

### 6.3 按多标签交集查找

```dataview
TABLE domain, tags
FROM "GBrain"
WHERE contains(tags, "中医基础理论") AND contains(tags, "阴阳")
```

## 七、综合检索示例

### 7.1 场景：写一篇文章需要引用心理学和学习方法

```dataview
TABLE file.name AS "实体", type AS "类型", domain AS "领域"
FROM "GBrain"
WHERE domain = "心理学" OR domain = "学习方法"
SORT domain ASC, type ASC
```

### 7.2 场景：寻找与技术相关的概念性知识

```dataview
TABLE file.name, domain, type
FROM "GBrain"
WHERE type = "concept" OR type = "technology"
SORT domain ASC
```

### 7.3 场景：查找连接数最多的"知识枢纽"

```dataview
TABLE length(relations) AS "连接数", domain AS "领域"
FROM "GBrain"
SORT length(relations) DESC
LIMIT 10
```

### 7.4 场景：学习新领域的入门路径

选择领域 → 查找 `type = "concept"` 的核心概念 → 跟随 `relations` 逐步深入：

```dataview
TABLE type, relations
FROM "GBrain"
WHERE domain = "新科技与应用" AND type = "concept"
SORT file.name ASC
```

## 八、自定义检索技巧

### 8.1 按创建时间检索最新实体

```dataview
TABLE domain, type, file.cday AS "创建日期"
FROM "GBrain"
SORT file.cday DESC
LIMIT 10
```

### 8.2 查找最近修改的实体

```dataview
TABLE domain, type, file.mday AS "最后修改"
FROM "GBrain"
SORT file.mday DESC
LIMIT 10
```

### 8.3 实体数量统计（按领域）

```dataview
TABLE length(rows) AS "实体数"
FROM "GBrain"
GROUP BY domain
SORT length(rows) DESC
```

### 8.4 快速模糊搜索（FTS5 全文检索）

> 在 Hermes 或代码环境中使用以下 CLI 命令：

```bash
# 在 GBrain 中搜索关键词
grep -rn "关键词" /home/ubuntu/Hermes-Obsidian/Hermes-Obsidian/GBrain/ --include="*.md" -l

# 搜索并显示匹配行
grep -rn "心流\|专注" /home/ubuntu/Hermes-Obsidian/Hermes-Obsidian/GBrain/ --include="*.md"
```

### 8.5 导出所有实体关系为表格

```dataview
TABLE file.name AS "实体", domain AS "领域", type AS "类型", relations AS "关系"
FROM "GBrain"
SORT domain ASC, file.name ASC
```
