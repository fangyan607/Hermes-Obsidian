# GBrain 实体创建模板

> 在 GBrain 中添加新实体时，复制本模板到对应领域目录。
> 每页代表一个独立概念，通过 `relations` 字段的 wikilink 连接其他实体。

---

## 使用方式

1. 将本文件复制到对应领域目录（如 `GBrain/心理学/`）
2. 按下方格式填写 frontmatter
3. 填写正文内容
4. 在 `关联知识` 部分添加 wikilink 连接
5. 更新 `GBrain/README.md` 中的领域关系图
6. 运行 `bash GBrain/init.sh` 验证 frontmatter 格式

---

```yaml
# ========== 从这里开始复制 ==========
---
title: {{实体名称}}
type: {{实体类型}}    # 可选值: concept | theory | method | practice | technology | law | therapy | technique
domain: {{所属领域}}  # 例如: 心理学 | 中医学 | 写作 | 法律 | 学习方法 | 创造性思维 | 新科技与应用
relations:
  - type: {{关系类型}}    # 如: 理论基础 | 跨域关联 | 方法论关联 | 互补方法 | 实践应用 | 技术支撑 | 等
    target: [[目标实体]]  # 同域直接写 [[实体名]]，跨域写 [[领域/实体名]]
  - type: {{关系类型}}
    target: [[目标实体2]]
  # 每个实体至少连接 2 个其他实体
  # 每个领域至少建立 2 条跨域连接
tags:
  - {{标签1}}
  - {{标签2}}
  - {{标签3}}
  - {{标签4}}
---
# ========== 复制结束 ==========
```

---

## 填写说明

### type（实体类型）

| 类型 | 含义 | 适用场景 |
|------|------|----------|
| `concept` | 核心概念 | 抽象的理论范畴、思想体系 |
| `theory` | 理论体系 | 有完整逻辑框架的学说 |
| `method` | 方法论 | 可操作的流程、方法、框架 |
| `practice` | 实践体系 | 临床、工程、创作等实操体系 |
| `technology` | 技术 | 具体的技术实现、工具 |
| `law` | 法律 | 法律法规、法典 |
| `therapy` | 疗法 | 心理治疗流派 |
| `technique` | 技法 | 具体技巧、手法 |

### relations（关系类型）

关系类型自由定义，但保持一致性。常用关系类型：

| 关系类型 | 含义 | 示例 |
|----------|------|------|
| `理论基础` | A是B的理论基础 | 阴阳五行 → 藏象学说 |
| `方法论关联` | A与B在方法论上关联 | 辨证论治 → 系统思考 |
| `跨域关联` | 跨领域的知识连接 | 认知科学 → 认知行为疗法 |
| `互补方法` | 相互补充的方法 | 刻意练习 ↔ 深度工作 |
| `计算支撑` | A为B提供计算能力 | 量子计算 → 世界模型 |
| `技术赋能` | A赋能B | 世界模型 → 具身智能 |
| `实践应用` | A是B的实践应用 | 方剂配伍 → 辨证论治 |
| `学派对比` | A与B是不同学派 | CBT → 人本主义 |
| `编纂关联` | A与B在法律体系中的关联 | 民法典 → 合同法 |

### 正文结构规范

每篇实体正文应包含以下部分：

```
# {{实体名称}}

## 一句话定义
> 用一两句话精确定义该实体。不超过 100 字。

## 详细说明
3-5 段详细解释。涵盖：起源/背景、核心内容、发展演变、当前应用。

## 核心要点
用 bullet points 列出 4-6 个最有价值的关键点。

## 关联知识
列出 wikilink 连接，每行附带简要说明关系。
- [[实体A]] — 说明A与当前实体的关系
- [[领域/实体B]] — 跨域连接需包含领域前缀

## 来源
列出参考来源（书籍、论文、报告等）。
```

## 示例

### 一个完整的实体页面

```markdown
---
title: 刻意练习
type: method
domain: 学习方法
relations:
  - type: 互补方法
    target: [[深度工作]]
  - type: 互补方法
    target: [[时间管理]]
  - type: 跨域关联
    target: [[创造性思维/认知科学]]
tags:
  - 练习
  - 专家
  - 技能习得
  - 反馈
---

# 刻意练习

## 一句话定义
> 刻意练习（Deliberate Practice）是一种有目的、有反馈、有挑战的重复训练方法，是通往卓越表现的系统性路径。

## 详细说明
刻意练习由心理学家安德斯·艾利克森（Anders Ericsson）提出，...
```
